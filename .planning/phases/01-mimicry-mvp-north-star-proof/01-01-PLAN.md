## Truths

- Implements D-09 (hybrid SDK-driving: native anthropic-sdk-go types + `option.WithHeader` escape hatch for the 12 identity headers), D-11 (PROF-02 enforcement seed — the Shaper has no zcode-specific code paths), D-12 (test-harness Turn Loop with a narrow interface), D-15 (tool execution stubbed — single-turn selection only).

<objective>

This is the TRACER — a single real round-trip through the actual provider with the actual profile. It is NOT the parity test (Plan 01-06) and NOT full-fidelity shaping (Plan 01-04). It proves the integration seam is real before any substrate is built out.
</objective>
