# Plan 05-02 — MCP lifecycle robustness: process-group spawn + group-signal shutdown + reaper (no zombies)

## Phase Goal

**As a** long-running ass-guard session, **I want to** spawn MCP servers and guarantee that on shutdown the ENTIRE process tree (including grandchildren the server forked) is reaped with no zombies, **so that** a session-heavy workday leaves the process table clean and a crashed MCP server's children don't outlive it.

## Truths

- Implements D-02 (process-group spawn via Setpgid, group-signal SIGTERM shutdown with SIGKILL escalation, reaper goroutine Wait4'ing the group in a loop to prevent zombies) and ECOS-02 (lifecycle-robust — no zombies).
- Carries the second Phase-5 success criterion: "MCP server subprocesses are lifecycle-robust — process-group spawn, group-signal shutdown, reaper goroutine prevent zombies."
- Builds on Plan 05-01's `internal/mcp.Host` (the spawn/list/call path). This plan hardens the spawn (process-group isolation) and adds the shutdown discipline (group signal + reaper). The Plan 05-01 tracer uses the SDK's default subprocess lifecycle; this plan replaces it with the robust variant. ROADMAP: "Phase 5 follows Phase 4 in the serialized-deltas discipline" — this plan serializes AFTER 05-01 (Wave 2, depends_on 05-01) because it modifies the same `Host`.

<objective>
Make MCP server subprocesses lifecycle-robust per D-02. Add `internal/mcp/lifecycle.go` (build-constrained `//go:build darwin || linux` — the v1 platform set): each spawned MCP server runs in its OWN process group (`cmd.SysProcAttr = &syscall.SysProcAttr{Setpgid: true}`), so signaling the group reaches grandchildren the server forked. On shutdown, `Host.Close()` sends `SIGTERM` to the negative PGID (the whole group), waits a bounded grace period, escalates to `SIGKILL`, and a per-server reaper goroutine calls `syscall.Wait4(-pgid, ...)` in a loop until `ECHILD` so reaped children (including grandchildren reparented after the server dies) NEVER become zombies. Wire `Host.Close()` into the session shutdown path (the logout/cancel hook added in Plan 05-01 T4 is the call site). Windows is out of scope for v1 (PROJECT.md) — a build-tagged stub returns a clear v2 error so the package still compiles on all platforms.
</objective>
