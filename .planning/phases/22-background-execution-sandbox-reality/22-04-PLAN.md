## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| model → persistent shell commands | Model-authored commands run with full inherited state in a long-lived shell |
| shell output (ANSI-laden) → tool result → transcript | Untrusted escape sequences must not reach the transcript or stdout |
| PTY master fd → process lifetime | A leaked fd outlives the session inside the editor-owned process |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-22-14 | Information Disclosure | PTY output escaping to stdout | high | mitigate | Capture flows only to the tool result + bounded buffer + stderr counters (transport discipline); the plan prohibition pins it; no code path writes the master to os.Stdout |
| T-22-15 | Tampering | ANSI/OSC sequences spoofing transcript content | medium | mitigate | StripANSI before any buffer/result (Task 1 table battery pins the scope); the nonce sentinel is unaffected by stripping (it is plain text) |
| T-22-16 | Denial of Service | wedged read loop after shell death | medium | mitigate | EIO-as-EOF terminates the read promptly (Task 2 battery); dead-shell state prevents spin; lazy restart bounded by the mutex |
| T-22-17 | Denial of Service | master fd exhaustion across session/load cycles | medium | mitigate | Drain in the OnClose chain + the fd-baseline battery (Task 3, Pitfall 5) |
| T-22-18 | (accepted) | model-authored command executes anything in the persistent shell | high | accept | T-8-33 posture: the model's command IS the product; the safety model is the pattern/hook table + manual cancellation — the persistent shell adds state, not authority (same user, same workdir) |
</threat_model>
