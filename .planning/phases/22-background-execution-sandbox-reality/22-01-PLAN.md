## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| child process output → notification block → model context | Background command output (untrusted bytes) is embedded into a wake-turn input block the model reads |
| model → task cancellation requests | The model names task ids it learned from notifications; a forged id must not cancel another session's work |
| completions → wake drain | Concurrent completion events race the single turn mutex |

| T-22-02 | Denial of Service | tracker pending queue + wake drain | medium | mitigate | Completion-time-ordered queue with task-id dedupe and single TryLock drain point — duplicate wakes and notification storms are impossible by construction (Pitfall 8, D-03); subagent queue is bounded (subagentQueueBound) |
