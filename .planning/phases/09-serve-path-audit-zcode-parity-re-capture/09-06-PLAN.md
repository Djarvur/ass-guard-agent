# Plan 09-06 — The per-session audit mirror: `--audit-log` on serve, header-name discipline, the secret canary

## Phase Goal

**As an** operator of a hands-off agent, **I want** every `acp serve` session to leave a redacted, bounded audit trail that records the engine's decisions, **so that** I can answer "what did the agent do, and why did it continue" from the log alone.

**This plan's slice:** the AUD-02 mirror leg + locked D-02 — the operator-facing audit artifact. The transcript (09-01/09-05) is the investigation index; this plan adds the compact per-session mirror under `.ass-guard/audit/` (default ON), the `--audit-log` operator override (today the flag exists but `runACPServeCmd` never reads it — the value dies unparsed-to-use), the shared stdout-rejecting sink opener, header-NAME capture on request events (Pitfall 9's audit-path discipline: names are shape evidence — the 12 identity headers are a TIER-2 mimicry invariant — values NEVER enter any artifact), and the automated secret canary that pre-runs the phase gate's token/secret greps. Discretion note (CONTEXT): rotation/pruning stays at per-session file boundaries (a new session = a new file — the natural retention boundary D-02 selected); no rotation machinery is built.

## Truths

- Carries AUD-02's mirror half ("plus an optional `--audit-log` mirror (0600, append-only JSONL, rejects stdout as a target)") and locked D-02 verbatim: per-session JSONL under `.ass-guard/audit/` as the default, `--audit-log` as the operator override, 0600, append-only, stdout rejected.
- v1.0 D-20 binds via CONTEXT ("the audit trail complements, never duplicates, the transcript writer"): the mirror is a SEPARATE compact artifact — a bus consumer like the tracer's AuditLogger, NOT a second transcript writer; research Anti-Pattern 3 is honored because the mirror never writes transcript lines and the transcript never writes mirror lines (different schemas, different consumers, one bus).
- Research ground truth: PITFALLS Pitfall 8 ("Reuse `openAuditSink` verbatim… no `os.OpenFile` for audit outside the shared opener"); Pitfall 9 (header-capture discipline on the audit path: every new header NAME audited against the redaction allowlist; all captured content through the one redaction chokepoint; the canary grep protocol); ARCHITECTURE Pattern 2 item 3 (the optional flat file reusing `audit.NewAuditLogger` semantics verbatim).
- The mirror rides plan 09-02's enriched `event.EngineDecision` (span + config source) — the "why did it continue" answer is available in the operator-tailable artifact too, not only the transcript.
- Header names ride `event.RequestShaped` as an ADDITIVE `HeaderNames []string` field populated by the capturer closure (keys only — the VALUES are dropped at the closure per 09-01's Pitfall 9 discipline; names cannot carry values).
- The canary test IS the phase gate's "token/secret canary greps clean" made repeatable: synthetic secret values through a real serve turn, then zero-occurrence greps over every artifact the phase gate names (audit log, transcript, body store, stderr).

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| event bus (provider bytes, model output, engine verdicts) → mirror files under .ass-guard/audit/ | The mirror persists a second copy of event-derived content to disk. |
| outgoing request headers → capturer closure → HeaderNames | Header content crosses from the adapter into events; values must die at the boundary. |
| mirror files ← operator tailing / phase-gate greps | The artifact is routinely read by humans and tooling. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-9-22 | Information disclosure | header VALUES leaking through HeaderNames into mirror lines | mitigate | The closure copies KEYS only (Test 8 asserts values absent from the published event); even so, every mirror line passes redact.Redact before write — two independent bars. |
| T-9-23 | Information disclosure | secret-bearing payloads in mirror lines | mitigate | Per-line redaction chokepoint (Test 4) + the Test 12 canary across ALL artifacts + stderr — the phase gate's own grep protocol, automated. |
| T-9-24 | DoS | a slow/blocked mirror sink stalling turns | mitigate | The mirror is a bus consumer with bounded buffers (drop propagates as bus drop, D-05) + drop-with-counter on write failure (Test 6) — never on the turn path, never fatal. |
| T-9-25 | Tampering | audit output on stdout corrupting the ACP frame stream | mitigate | Triple guard: OpenFileSink rejects stdout targets by path; NewMirrorFile panics on os.Stdout; the canary harness asserts stdout stays frame-only (inherited from 09-01's Test 12). |
| T-9-26 | Spoofing | cross-session line injection (one session's lines attributed to another) | mitigate | Routing is derived from the trusted TurnID prefix (engine/session minted), not from event content; per-session files are append-only with distinct handles. |
