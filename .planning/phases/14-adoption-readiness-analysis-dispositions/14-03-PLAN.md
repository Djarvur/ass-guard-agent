# Plan 14-03 — pi↔shaper cross-validation: hardening the wire chokepoint against a 43k-line behavioral spec

## Phase Goal

**As the** operator about to daily-drive ass-guard, **I want** the north-star component (the request
shaper — the thing whose structural indistinguishability everything else stands on) cross-validated
against an independent implementation of the same wire protocol, **so that** latent shaping bugs are
found by diffing against pi's battle-tested wire layer instead of waiting for drift to surface in
daily use (ECOSYSTEM-AUDIT §5-1: "hardens exactly the component the north star depends on").

**This plan's slice:** EARLY-04 — a committed audit diffing internal/shaper against pi's
`anthropic-messages.ts` (1,370 lines) + `transform-messages.ts` (223 lines) + its test suite, every
divergence dispositioned (fixed / justified in-repo / routed with rationale). The zcode corpus, not
pi, is the target; pi is the behavioral spec to diff against.

## Truths

- The pi clone is GONE from disk (orchestrator fact) — this plan re-clones shallow under
  `tools/pi-audit/` (public repo, `git clone --depth 1 https://github.com/earendil-works/pi`),
  records the resolved HEAD commit hash in the audit, and NEVER commits the clone into the repo
  (.gitignore entry `tools/pi-audit/`). License: pi is MIT (IDEA-LANDSCAPE source table) —
  idea-level study and behavioral diffing are unambiguously fine; the no-mechanical-porting
  prohibition is discipline, and the zcode-corpus-authority rule is the fidelity constraint.
- The four locked dimensions (from the requirement + ECOSYSTEM-AUDIT §5-1): cache_control
  placement, thinking-config mapping, header merge order, compat-flag catalog — plus
  transform-messages.ts's message-shape mapping as a fifth diff surface.
- Known planning-time facts the audit must engage: the shaper currently emits NO cache_control
  (grep-verified: zero matches in internal/shaper) while live zcode captures DO carry it (46
  lines in one 2026-08-19 session) — the cache_control dimension starts as a KNOWN divergence
  candidate, resolved jointly with 14-02's corpus evidence (corpus wins).
- Capture authority hierarchy (locked): zcode corpus > in-repo justification > pi behavior. A pi
  behavior zcode never exhibits is a JUSTIFIED divergence (we match the target, not pi).

## Objective

Clone pi at a pinned commit; read the wire layer; diff internal/shaper against it dimension by
dimension; commit the audit with every row dispositioned; apply the fix-dispositions as minimal
capture-faithful changes with RED→GREEN tests.

Purpose: EARLY-04 — north-star hardening of exactly the wire chokepoint.
Output: docs/shaper-pi-audit.md, tools/pi-audit clone procedure (gitignored), minimal shaper fixes
where dispositioned.
