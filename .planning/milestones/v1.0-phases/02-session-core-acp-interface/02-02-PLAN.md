# Plan 02-02 — Session Core: transcript (one artifact) + projector (lean window) + turn loop

## Truths

- Implements D-03 (append-only JSONL transcript — every line a structured JSON object, single source of truth), D-17 (Session Core owns transcript + projector + turn loop in ONE package `internal/session`; Session Manager is sole transcript owner via append/read API), D-18 (the 6-step turn cycle as a method on Session Core), D-20 (audit log = transcript, ONE artifact — the per-session JSONL captures everything with LOG-03 redaction per-line), D-01 (lean seed = system prompt + task summary + current user message + ZERO carry-forward), D-02 (task summary = MECHANICAL extraction, no model call — the deferred extraction rule + N-char policy from RESEARCH §4.3).
- Carries SESS-01 (two-layer context model — durable transcript + lean projected window), SESS-04 (boundary resets window to lean seed), SESS-05 (boundary markers durable — rehydration part MOOT per D-09, durability part LIVE), SESS-06 (Session Manager sole transcript owner), LOG-02 (async bus consumer — the transcript writer subscribes to the bus async, behind the channel buffer, never in the critical path), LOG-03 (per-line redaction via `internal/redact`).
- Replaces the Phase-1 `internal/loop` test-harness turn loop (Phase-1 D-12). The Phase-1 `internal/audit` AuditLogger is FOLDED into the transcript writer (D-20 — one artifact, one writer, no two-writer drift). The Phase-1 event bus seed (`internal/event`) is EXPANDED into typed channels — but that expansion's full wiring lands in Plan 02-03 (mutability/boundary) + 02-04 (streaming); this plan builds the transcript writer against the bus API as it exists and adds the channel-subscription shape the writer needs.
- Tool execution stays STUBBED (D-18 step 5; Phase-1 D-15) — the turn loop parses tool_calls, appends a stub tool_result, and loops. Real execution is Phase 4. Subagent dispatch is Plan 02-05.

<objective>
Build the Session Core — the component that owns the transcript (the one audit artifact per D-20), projects the lean model-visible window at each turn boundary (D-01/D-02), and runs the turn loop (D-18). This plan replaces the Phase-1 test-harness loop with a real Session Core: the Session Manager is the sole transcript writer (append-only JSONL under `.ass-guard/`), the projector builds the lean window by mechanical extraction (no model call), and the turn loop wires the Phase-1 Shaper + Provider into the streaming cycle. After this plan, the ACP server from Plan 02-01 can swap its stub turn loop for the real Session Core.
</objective>
