# Plan 02-04 — Streaming infrastructure: expanded event bus (typed channels) + Provider.Stream + semaphore

## Truths

- Implements D-04 (event bus EXPANDED into typed Go channels — one channel per event type; producers send, consumers select — the Phase-1 seed grows into the channel shape), D-05 (bounded buffer + block per channel kind per RESEARCH §2.3 — AgentMessageChunk=128, others 4-32), D-18 step 4 streaming infrastructure (Provider.Stream reads SSE chunks and emits them — the Session Core wiring to consume Stream lands in Plan 02-05), D-12 (provider semaphore bounds parent + subagent concurrency — default 6, configurable).
- Carries ACP-04 (the streaming PATH infrastructure — Provider.Stream + the bus that carries chunks; the end-to-end ACP wiring is Plan 02-05), PARA-04 (the semaphore), LOG-02 (the expanded bus enables the async transcript writer — full subscription wiring in Plan 02-06).
- This plan touches ONLY `internal/event` + `internal/provider` — zero file overlap with 02-02 (`internal/session`) or 02-03 (`internal/toolcat`), so it runs in Wave 2 parallel with 02-02. It depends on 02-01 only because the bus interface contract was seeded there (the tracer's stub bus usage); the expansion is backward-compatible.

<objective>
Build the streaming infrastructure that Plan 02-05 wires into the ACP server + Session Core: expand the Phase-1 event bus into typed Go channels (D-04) with bounded buffers (D-05), add the full event-type catalog (RequestShaped, AgentMessageChunk, ToolCall, ToolCallUpdate, UsageUpdate, SubagentResult, Boundary), add `Provider.Stream` (the SSE-to-chunks method that replaces the non-streaming Send for live turns), and add the provider semaphore (D-12 — bounds parent + subagent concurrency). After this plan, the Session Core (02-02) and ACP server (02-01) can be wired to stream token-by-token (Plan 02-05).
</objective>
