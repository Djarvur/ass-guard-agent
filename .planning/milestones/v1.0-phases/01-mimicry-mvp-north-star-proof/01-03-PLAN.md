<threat_model>
- **T-01-06 (LOW — schema injection via a malicious profile):** a hand-crafted profile could declare a tool schema with malicious intent (e.g. an `input_schema` that exploits a JSON-schema parser bug). Mitigation: the catalog's `InputSchema` is `json.RawMessage` (stored, not executed); the adapter validates structurally (parse-only in Phase 1); no profile-supplied schema is ever `eval`'d or used to generate code. The threat is LOW because schemas are data, not code; the only consumer is the model + a structural validator. Phase-5 MCP hosting (ECOS-01) will need a fuller MCP-schema threat model — out of Phase-1 scope.
</threat_model>
