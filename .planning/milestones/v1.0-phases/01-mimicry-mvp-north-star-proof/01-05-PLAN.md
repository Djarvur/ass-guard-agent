<threat_model>
- **T-01-09 (MEDIUM — audit log leaks secrets):** the verbatim shaped request carries auth headers (`authorization`, `x-api-key`); a redaction regression leaks them to the audit file. Mitigation: `internal/redact` is the single chokequepoint (tested in Plan 01-01 T2); T2's audit test explicitly asserts the auth value is `[REDACTED]`; the sink is never stdout. Severity MEDIUM because the audit log may be a persistent file (larger blast radius than stderr).
- **T-01-10 (LOW — `profile check` spawns an untrusted zcode binary):** the `--zcode-bin` flag could point at an arbitrary executable; the command runs it with the operator's keys. Mitigation: the default is `zcode` on PATH (operator's own install); the operator explicitly provides `--zcode-bin` to override; this is an operator-facing tool, not a network service — the threat model is "operator shoots own foot," which is acceptable for a dev tool. Document in `--help` that `--zcode-bin` runs the named executable.
</threat_model>
