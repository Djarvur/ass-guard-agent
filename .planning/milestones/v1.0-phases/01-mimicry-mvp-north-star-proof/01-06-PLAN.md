# Plan 01-06 — The A/B parity test: curated divergence suite + two-layer metric + the gate

## Truths

- Implements D-01 (curated divergence set of 5–15 prompts, each with a documented divergence-probe rationale), D-02 (two-layer metric: tool-name sequence equality AND per-tool argument structural equality with explicit normalization rules), D-03 (100% threshold — the literal gate, not a soft checkpoint), D-04 (temp=0 determinism — every mismatch points at the Shaper), D-05 (the zcode arm is replay of captured tool-call output from the rollout JSONL — offline, reproducible).
- Resolves RESEARCH-FLAG-01: the held-out split is adopted — the curated suite is drawn from the `eea3dc48` session's real turns; `016eee8a` is a second held-out set for a surprise check. Profile extraction (request shape) and parity reference (tool-call sequences) are different layers, but the split removes the overfitting concern entirely.
- Carries MIMC-03 (the behavioral A/B parity test) and MIMC-04 (byte-identical is explicitly out of scope — structural indistinguishability is the bar). This plan IS the project's reason to exist: PASS = thesis proven; FAIL = stop-and-replan (PROJECT.md Anti-Pattern 5).

<objective>
