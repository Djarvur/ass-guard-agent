The system-prompt blocks ARE the mimicry payload (not secrets) — they are checked in byte-faithful, which is correct.
- **T-01-05 (LOW — extractor reads the wrong product's transcripts):** if the extractor fell back to `~/.claude/projects/`, it would silently extract a Claude Code (not zcode) profile. Mitigation: T2 reads exclusively from `~/.zcode/cli/rollout/` via the `-rollout-dir` flag; the stale path is never referenced in code; T4's verify greps for the stale path and asserts absence.
</threat_model>
