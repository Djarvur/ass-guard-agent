# Plan 04-01 — Tracer: unified engine decision core (the zero-continue spine)

## Phase Goal

**As an** SDD practitioner, **I want to** run an OpenSpec workflow through ass-guard and have the agent advance stage-to-stage with zero manual "continue" taps when the assistant's output matches a known handoff, **so that** the structural safety property holds (unmatched output triggers nothing) and an engine failure never prevents a turn from completing.

## Truths

- Implements D-01 (post-turn observer — the engine runs AFTER `Session.Prompt` returns `end_turn`, never inside the turn loop's critical path), D-02 (dual-signal detection — text-pattern match OR known handoff tool-call), D-03 (structural safety — unmatched output triggers nothing; the only off-switch is manual cancellation), D-04 (graceful degradation — an engine panic is recovered and the original turn's `(stop, err)` are returned unchanged), D-05 (provenance tagging — every decision carries the source turn id + the matched signal).
- Carries ENG-01 (one engine decides continue/hook/ask/wait/nothing after turn-complete), ENG-02 (hooks are an engine action — one decision point, one provenance-tagged stream — the `EngineDecision` event/line is the single stream), ENG-03 (unmatched → nothing; the engine holds a cancel-aware injection queue that drains on `session/cancel`), ENG-04 (engine panic → turn completes), ENG-05 (the engine emits a provenance-tagged `EngineDecision` per turn — the dual-signal detector + the action chosen).
- This is the **TRACER**: the thinnest end-to-end slice proving the phase's reason to exist. A fake provider returns a turn whose assistant text matches a seeded handoff pattern → the engine decides `continue` → injects the next-stage prompt → the fake provider returns `end_turn` → the loop exits. A turn with NO match → the engine decides `nothing` → no injection → the loop exits (structural safety). A panicking decider → the wrapper returns the original `(stop, err)` (graceful degradation). The OpenSpec subprocess adapter (04-02), the hook-DAG (04-03), the real tool executor (04-04), learning mode (04-06), and full ACP wiring (04-05) are OUT of this plan — the tracer consumes an injected `PatternTable` (an interface) and an injected `TurnRunner` (the seam it wraps), both defined here.

<objective>
Establish the thinnest possible end-to-end zero-continue slice: (1) the engine's pure `Decide(turnOutput, table) Decision` function applies dual-signal detection (text-pattern OR handoff tool-call) and returns one of {continue, hook, ask, wait, nothing}; (2) the `Observe` wrapper runs after `TurnRunner.Run` returns `end_turn`, reads the just-finished turn's output, calls `Decide`, and for `continue` re-enters `TurnRunner.Run` with the next-stage prompt (a real turn); (3) structural safety — unmatched input ⇒ `nothing` ⇒ no re-entry; (4) graceful degradation — a panic in `Decide`/the wrapper is recovered and the original `(stop, err)` are returned; (5) provenance — every `EngineDecision` event/line carries the source turn id + matched signal. The tracer round-trips a fake-pattern-table fixture + a fake TurnRunner: handoff text ⇒ one continue injection ⇒ end_turn ⇒ loop exits; unmatched text ⇒ zero injections; injected panic ⇒ original stop returned. No network, no `openspec` binary — the fake TurnRunner stands in for the Session Core.
</objective>

// PatternTable is the dual-signal source the engine consults (D-02). The
// concrete loader (TOML, from the openspec overlay) lands in 04-02; the engine
// depends only on this interface so 04-01 is dep-free.
type PatternTable interface {
    // MatchText scans assistant text for a known handoff pattern. Returns the
    // matched pattern's id + action, or ("", ActionNothing) if no match.
    MatchText(text string) (patternID string, action Action)
    // MatchTool reports whether name is a known handoff tool-call and returns
    // its action (D-02 second signal).
    MatchTool(name string) (toolID string, action Action)
}

// Action is the engine's decision vocabulary (D-02 + D-08 step kinds the engine
// can dispatch). 04-01 implements continue + nothing; hook/ask/wait are carried
// as values (the dispatch lands in 04-05/04-06).
type Action int
const (
    ActionNothing Action = iota  // structural safety: unmatched → nothing (D-03)
    ActionContinue               // inject the next-stage prompt (a real turn)
    ActionHook                   // launch a hook-DAG (wired in 04-05)
    ActionAsk                    // surface a session/update + wait (wired in 04-06)
    ActionWait                   // delay / timed re-check
)

// Decision is one engine verdict for one turn (ENG-02 — the single
// provenance-tagged stream). The wrapper emits an EngineDecision event + writes
// an engine_decision transcript line for EVERY turn (including ActionNothing,
// so the audit log proves the structural-safety property).
type Decision struct {
    TurnID      string  // the source turn (provenance, D-05)
    Action      Action
    Signal      string  // "text:<patternID>" | "tool:<toolID>" | "unmatched"
    NextPrompt  []session.ContentBlock // populated for ActionContinue
    Reason      string
}

// TurnRunner is the seam the engine wraps (the Session Core turn). The engine
// calls Run once for the user's prompt, then once per continue-injection.
type TurnRunner interface {
    Run(ctx context.Context, prompt []session.ContentBlock) (stop string, err error)
    // LastTurnOutput returns the assistant text + tool-call names of the most
    // recent turn (the engine inspects this). 04-05's real impl reads the
    // transcript via Manager.ReadSince; the tracer's fake returns canned bytes.
    LastTurnOutput() TurnOutput
}

type TurnOutput struct {
    TurnID     string   // the last assistant_message's TurnID (provenance)
    Text       string   // the final assistant text
    ToolCalls  []string // the names of tool calls in this turn (handoff signal 2)
}
