# Plan 11-03 — The recording proxy: dsh wire truth at the configured baseURL

## Phase Goal

**As an** operator routing DeepSeek-model turns, **I want** a second mimicry profile whose content is captured from deepseek-harness's real wire traffic, **so that** ass-guard's requests are structurally indistinguishable from dsh's — proving the N-profile thesis with no target-specific code paths.

**This plan's slice:** DSH-03's capture half. dsh's session JSONL stores session EVENTS, not outgoing requests — the wire truth (assembled system prompt, tools array, identity headers, message shape) exists only on the HTTP wire. Because dsh's custom-provider `baseURL` is configurable (`$DSH_HOME/settings.yaml` → `llm-pi-ai.providers.<id>.baseURL`, verified in research §1), a POSITIONED plain-HTTP reverse proxy on localhost captures it exactly — no TLS MITM, no interception. This plan builds that proxy as a dev-time CLI (`cmd/dsh-proxy`, a sibling of `cmd/extract-profile` — never linked into the ass-guard runtime), implementing the recording contract the extraction (11-05) and the system-form decision consume.

## Truths

- Research §1 verified the config surface: `llm-pi-ai.providers.<id>` with `api: openai-completions`, arbitrary `baseURL` (docs name self-hosted gateways as the use case), credentials in `$DSH_HOME/.credentials.yaml`, and a GET /models call the proxy must pass through.
- The proxy is deliberately boring: stdlib `httputil.ReverseProxy` + a record hook + `internal/redact`. The recording contract (research §3) is the load-bearing part — every request line must carry the full messages array, tools with strict, field census, headers, and tool-result shapes verbatim, because the extraction, the one-vs-N system-form decision, and the traceability audit all read THIS file.
- SSE responses (dsh is always-stream) must be captured WITHOUT breaking the stream — tee the body, pass chunks through as they arrive.
- Redaction at RECORD time, not post-hoc: the capture file may be inspected/shared; Authorization values never touch disk (research §Security Domain). Identity header NAMES survive — they are the mimicry fingerprint.
