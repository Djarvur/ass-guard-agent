# Plan 08-03 — OpenSpec adapter reconciliation: probe-pinned surface + real Execute + subprocess guards

## Phase Goal

**As a** developer practicing SDD, **I want to** kick off and drive an entire OpenSpec change (`/opsx:explore → propose → apply → archive`) from ass-guard by typing the toolkit's own slash-commands, **so that** the unmodified workflow runs hands-off.

**This plan's slice:** when the model invokes `openspec:list` / `openspec:status` (the structured alternative to shelling through Bash — `/opsx:update` literally reads `openspec status --change <name> --json` output), the tool must actually RUN. Today `RegisterTools` registers catalog entries with no `Execute` (the Adapter is constructed nowhere outside tests), and the seeded command set names phantom subcommands (`apply`/`implement` don't exist on the binary). This plan reconciles the surface to the installed binary's probe and makes every registered tool real.

## Truths

- Carries CMD-03 fully: Adapter-backed Execute on registered tools; command surface pinned to the installed binary's probe (phantom apply/implement removed; read-only vs mutating classified); non-interactive guards (nil stdin, per-command timeout, exit-code classification).
- Implements D-10 (structured error to the model — exit code, stderr, classification; the model adapts, no user-visible session/update note, no fail-loud halt).
- The hosting-model correction (PITFALLS Pitfall 7): the workflow is driven by agent-executed command files (08-04/08-06); the binary is SUPPORTING tooling. Reconciliation is a re-model, not a rename.
- Version-drift trap (Pitfall 7.2): the surface pins to the INSTALLED binary's probe (v1.5.0 on this machine, per the v1.1 research live probe), never to docs of the moving main branch (npm main is 1.9.0 with a different surface). A gated drift test re-probes when the binary is present.

Rebuild the OpenSpec tool surface against ground truth and make it executable end-to-end: (1) replace `seeded.toml`'s `[commands]` (today: list/show/validate/apply/implement) with the probe-derived table — read-only `list, show, validate, status, instructions, context, doctor, templates, schemas` (+ `spec`/`change` read subcommands), mutating `archive, new change, init, update, config set|unset|reset, schema fork|init, store setup|register|unregister|remove, workset create|remove` — with phantom `apply`/`implement` deleted and human-only `view`/`workset open`/`config edit` never registered; (2) give `RegisterTools` Adapter-backed `Execute` closures so model-invoked `openspec:*` calls run the binary and return `{stdout, stderr, exit_code, classification}` JSON; (3) harden `Adapter.Run` with a per-command timeout, `OPEN_SPEC_INTERACTIVE=0` in the child env, nil stdin, and per-command exit-code classification (ok / fixable-finding / hard-error / timeout / not-found) so fixable findings surface as actionable model-facing results instead of hard errors (D-10).
