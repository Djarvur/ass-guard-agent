# Plan 13-03 — The unmatched-ending advisory: engine decision class + client note + dedupe (OS-02, D-02, D-05)

## Phase Goal

**As a** developer practicing SDD with OpenSpec, **I want** the toolkit's full command matrix to run
end-to-end through ass-guard with zero-continue chaining, **so that** the unmodified toolkit works
hands-off — and when it genuinely needs me, it says so through the question surface instead of stalling.

**This plan's slice:** OS-02's second half. Phase 8 rejected auto-continue on question-shaped endings as
structurally unsafe (unmatched ⇒ nothing stands); 12-01 gave the model a real AskUserQuestion surface; this
plan adds the D-02 engine advisory — on an unmatched question-shaped ending the engine SUGGESTS (audit +
one client-visible note per class per session) that the model re-ask via AskUserQuestion, while holding
nothing. The advisory must read as routing help, never as the chain being held open — that distinction is
the safety story and the battery's spine.

## Design dispositions (the two PATTERNS flags, resolved in-plan)

1. **Dedupe state home (PATTERNS: no analog):** the Engine is stateless BY DESIGN and stays so. The dedupe
   state is a per-session map on the ACP-side wrapper — `advisorySeen map[string]map[string]bool`
   (sessionID → class set) on `sessionTurnRunner`, which already holds per-process state (`reg`,
   `patternTable`, `sessions`). Lazily initialized; consulted/cleared alongside the session lifecycle; size
   is bounded by (sessions × classes), both small. Nothing about this state reaches Decide.
2. **Post-turn emission point (PATTERNS timing hazard):** the ask surface reaches the client via a bus
   publish ONLY because Run's chunk forwarder is subscribed mid-turn — after the turn ends it has drained
   and exited. The advisory therefore emits DIRECTLY: Run subscribes the EngineDecision kind
   (event.BufEngineDecision) through a small collector goroutine mirroring startChunkForwarder's
   promptDone/done drain pattern, and after `<-done` applies the dedupe and calls
   `emit.AgentMessageChunk(dec.TurnID, note)` — emit is still in hand at that point in Run.

## D-02's model-initiated half (locked; implementation is discretion)

The model's awareness of AskUserQuestion rides 12-01's shipped surface: the tool is in the captured catalog
with its captured schema (the mimicry contract forbids catalog/system-prompt additions). This plan verifies
from 13-01's committed matrix captures + preserved transcripts whether the model already invokes it at
interactive points; if the harvest shows it does not, the ONLY sanctioned awareness lever is engine-owned
injected user-turn content (a seeded row's next-prompt text naming the tool — the same injected-user-message
channel chaining already uses). The lever edits internal/openspec/seeded.toml — a 13-02 artifact, which is
why this plan depends on 13-02 and lists seeded.toml in files_modified. Toolkit files
(`.claude/commands/opsx/*.md`) are read-only and stay untouched; the captured catalog is never rewritten.
The evidence + any lever used is recorded in the SUMMARY — and lever application triggers the MANDATORY
gated dead-end re-proof (Task 2's onboard-tutorial leg: the ask surfaced or the advisory fired).
