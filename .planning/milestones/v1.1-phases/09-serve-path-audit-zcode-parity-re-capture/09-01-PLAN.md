# Plan 09-01 — Factory capturer seam: both shapes, one construction site, serve-path RequestShaped (THE write-once seam)

## Phase Goal

**As an** operator of a hands-off agent, **I want to** have every `acp serve` session leave a redacted, bounded audit trail that also records the engine's decisions, **so that** I can answer "what did the agent do, and why did it continue" from the log alone and trust that the mimicry hasn't drifted.

**This plan's slice:** the operator's first observable audit capability — a serve-path provider request now leaves a redacted `request_shaped` line in the session transcript, produced through ONE factory-seam capturer shared by the tracer and the serve path (and inherited unchanged by Phase 10's `internal/runtime` extraction). Today the tracer path is the only audited path (`tracerProvider` reconstructs the Anthropic adapter locally in `cmd/ass-guard/provider_factory.go:90-109`), while `acp_serve.go`'s `makeProvider` calls `factory.Build` whose interface cannot attach a capturer — so `event.RequestShaped` is NEVER published on `acp serve` (AUD-01's verified gap, PITFALLS Pitfall 8). This plan lands the seam in its final home: written once, not re-wired.

## Truths

- Carries AUD-01 (single-sourced factory-seam capturer covering both protocol shapes; tracer refactored onto the same seam; the copy-`tracerProvider` shortcut is BANNED — Pitfall 8) and the RequestShaped-transcript half of AUD-02.
- Research ground truth: ARCHITECTURE Pattern 2 (verified current state: `makeProvider` at `acp_serve.go:272` builds with no capturer; `NewTranscriptWriter` has zero non-test callers; the recommended `capturedProvider` generalization is exactly this plan's `BuildWithCapturer`); PITFALLS Pitfall 8 (single-source the seam; integration test closing the shipped gap permanently; warning signs: "two functions with 'capturer' in their names, a comment saying 'mirrors tracerProvider'").
- Discretion decision (CONTEXT "Claude's Discretion"): the **`CurrentTurnID()` accessor is implemented**, not the empty-TurnID fallback — AUD-02's correlation IDs (session/turn/request) need turn attribution on every RequestShaped line, the accessor is ~6 lines on the existing `turnCounter atomic.Int64`, and the empty-TurnID fallback is documented as the rejected alternative (kept in the plan text for the executor's context, not implemented).
- Discretion decision: the captured-provider helper shape is a **`BuildWithCapturer` method on `scheduler.ProviderFactory`** (not a package-level helper in cmd/) — the factory owns provider construction (Phase-7 D-08 single-sourcing); Phase 10's runtime extraction then inherits one call site.
- v1.0 Phase-2 D-03/D-20 bind: the transcript stays the ONE per-session artifact with ONE writer (TranscriptWriter); this plan wires that writer on the serve path (it exists with zero non-test callers) and adds no second session artifact. The audit-mirror file (locked D-02) is a LATER plan (09-06), deliberately separate from the transcript.
- Redaction already exists (`internal/redact`; `Manager.appendLine` redacts every line) — nothing to build; this plan proves it with a canary-style assertion inside the integration test.
