## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| tool-result content → summarizer input → durable seed | untrusted repo/file content shapes the summary that becomes every future request's seed |
| provider error text → retry decision | the overflow matcher gates a forced compaction + resend |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-19-08 | Tampering | prompt injection via tool output steering the durable seed | medium | mitigate | Extractive summary prompt (Task 1 behavior); the seed is data inside a user-role message, never executed; input is already-redacted transcript content; summary length hard-capped (2048) so injected content cannot bloat the seed (DoS containment) |
| T-19-09 | Information Disclosure | summary persisting secrets from earlier turns | medium | mitigate | Summarizer input is redacted-transcript content only; the marker append rides the redacted chokepoint (19-03 Task 1's counting proof) |

| T-19-11 | DoS | retry loops on persistent overflow | low | mitigate | Per-turn single-attempt guard (Pitfall 8) pinned by the fail-twice test; compaction itself is append-only and non-destructive |
